\section{PagedAttention Kernel Compatibility}
\label{app:kernel}

Our head-specific admission policy results in a ragged KV cache structure where sequence lengths vary significantly across heads. To perform attention operations over this irregular structure, we can employ vLLM's PagedAttention \cite{pagedattn} kernel, which natively supports variable sequence lengths across the batch dimension. By reshaping the attention input---folding the head dimension ($H$) into the batch dimension ($B$)---the computation can be treated as $B \times H$ independent sequences of varying lengths. This allows existing serving systems to apply industry-standard CUDA kernels to compute attention over the ragged KV cache seamlessly.
